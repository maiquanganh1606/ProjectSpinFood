# ProjectSpinFood — SpinFood ♡

Một vòng quay đáng yêu để hai bạn quyết định hôm nay ăn gì.

## Chạy dự án

Đây là web tĩnh, chỉ cần mở `index.html` trong trình duyệt. Dữ liệu thực đơn và lịch sử được lưu cục bộ trong trình duyệt bằng `localStorage`.

## Deploy lên GitHub Pages

1. Mở repository trên GitHub: `https://github.com/maiquanganh1606/ProjectSpinFood`.
2. Vào **Settings** → **Pages**.
3. Trong **Build and deployment**, chọn **Deploy from a branch**.
4. Ở phần Branch, chọn `main`, thư mục `/(root)`, rồi bấm **Save**.
5. Đợi GitHub build trong khoảng 1–2 phút. Trang sẽ có địa chỉ: `https://maiquanganh1606.github.io/ProjectSpinFood/`.

Trên điện thoại, mở link này bằng Safari (iPhone) hoặc Chrome (Android), chọn **Add to Home Screen / Thêm vào Màn hình chính** để dùng như một ứng dụng. Thực đơn, ảnh và lịch sử được lưu cục bộ trên điện thoại đó.
