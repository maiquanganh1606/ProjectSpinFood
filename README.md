# SpinFood ♡

Một vòng quay đáng yêu để hai bạn quyết định hôm nay ăn gì.

## Chạy dự án

Đây là web tĩnh, chỉ cần mở `index.html` trong trình duyệt. Dữ liệu thực đơn và lịch sử được lưu cục bộ trong trình duyệt bằng `localStorage`.

## Deploy GitHub Pages

Sau khi đẩy repository lên GitHub, vào **Settings → Pages**, chọn **Deploy from a branch**, rồi chọn nhánh `main` và thư mục `/(root)`.
